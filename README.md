# N8N-Based-CRM

Monorepo for a CRM project that includes backend services, frontend app, infrastructure assets, and n8n workflow definitions.

## Repository Structure

- backend/ - Python backend service and Alembic migrations
- frontend/ - Frontend application
- infra/ - Infrastructure and deployment assets
- n8n/ - n8n scripts and exported workflows
- docs/ - Project documentation
- docker-compose.yml - Multi-service orchestration config

## Getting Started

- Review docker-compose.yml to understand available services and ports.
- See backend/requirements.txt for Python dependencies.
- See frontend/ for frontend setup details.
- n8n/workflows contains exported workflow JSON files.
